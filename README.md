## Hi, I'm Jasper

Senior .NET engineer, freelance since 2022. I build and maintain open-source .NET libraries, mostly around time, reactive programming and home automation.

### Open source

- [**Occurify**](https://github.com/Occurify/Occurify): define, filter, transform and schedule instant and period timelines in .NET.
- [**CodeCasa**](https://github.com/DevJasperNL/CodeCasa): .NET libraries with NetDaemon extensions and smart home automation utilities. [CodeCasa.Showcase](https://github.com/DevJasperNL/CodeCasa.Showcase) shows them in a real setup.
- [**Reactive.Boolean**](https://github.com/DevJasperNL/Reactive.Boolean): Reactive Extensions for `IObservable<bool>`.
- [**DependencyInjection.Composite**](https://github.com/DevJasperNL/DependencyInjection.Composite): contextual scoping for `Microsoft.Extensions.DependencyInjection`.
- Contributor to [**NetDaemon**](https://github.com/net-daemon/netdaemon).
